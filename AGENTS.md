# AGENTS.md

Instructions for AI coding tools (Codex and others) working in this repo.

Read, in order:

1. [`.claude/HANDOFF.md`](.claude/HANDOFF.md) — current state and task queue
2. [`.claude/STANDING_RULES.md`](.claude/STANDING_RULES.md) — how we work (binding for all AI tools)
3. [`.OpenAI/AGENTS.md`](.OpenAI/AGENTS.md) — Codex/OpenAI-specific context
4. [`.claude/CLAUDE.md`](.claude/CLAUDE.md) — project facts

These rules bind **every** AI tool, not just Codex — Claude, Ollama, Kimi, Grok,
Gemini and any other. If your tool reads a different instructions file
(`GEMINI.md`, a system prompt, …), point it at this file. In particular, follow
the three-phase model and effort plan in standing rule 3 (gather: Medium,
plan: High, implement: Medium).
